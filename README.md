# Parachute Fall – Privacy Policy and Terms of Use

The legal pages of the mobile game **Parachute Fall** (Android package `com.patpatt.game`), published with GitHub Pages:

- Privacy Policy: **https://therooster0.github.io/parachute-fall-privacy/**
- Terms of Use (with the purchase and refund terms): **https://therooster0.github.io/parachute-fall-privacy/terms.html**

- Two static pages (`index.html`, `terms.html`) in English, Turkish, German, French, Italian, Chinese, Arabic, Polish and Spanish. The English versions are the reference.
- Each page picks its language from `?lang=xx` (the game's Settings links pass the game's language), then from the browser's languages, and falls back to English. Without JavaScript all languages are shown one after another.
- No cookies, analytics, trackers or external resources, so no cookie banner is needed.
