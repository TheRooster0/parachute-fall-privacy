# Parachute Fall – Privacy Policy

The privacy policy of the mobile game **Parachute Fall** (Android package `com.patpatt.game`), published with GitHub Pages:

**https://therooster0.github.io/parachute-fall-privacy/**

- One static page (`index.html`) in English, Turkish, German, French, Italian, Chinese, Arabic, Polish and Spanish. The English version is the reference.
- The page picks its language from `?lang=xx` (the game's Settings link passes the game's language), then from the browser's languages, and falls back to English. Without JavaScript all languages are shown one after another.
- No cookies, analytics, trackers or external resources.
